# Singulario

Прототип заводской головоломки на Godot 4.7 (.NET / C#). Игрок находится внутри
Сингулярности, собирает частицы вращающимися ядрами и выбрасывает наружу объекты
вселенной. Подробности дизайна — в дизайн-документе:
https://claude.ai/code/artifact/9cf8f132-726d-4cf1-b623-86551e34a7c4

## Что сейчас есть в прототипе

- Разреженная сетка чанков с ленивой генерацией.
- Ядра с кольцом из 8 позиций (2/4/8 гнёзд), тиры Ж/К/С и серое, спин,
  передача частиц соседям по 4 сторонам; поворачиватель и бросатель.
- Источники частиц (кластеры с истощаемым запасом) и чёрные дыры.
- Панель установки ядер, камера, сохранение и загрузка поля в JSON (Экспорт/Импорт).

## Структура

| Папка | Что внутри |
| --- | --- |
| `Scenes/` | `Main.tscn` — главная сцена |
| `Scripts/` | весь C#-код (`NucleusLayer.cs` — симуляция и отрисовка ядер) |
| `Resources/Textures/` | текстуры, используемые игрой |
| `Resources/Shaders/` | шейдеры |
| `Resources/` | исходники `.aseprite`, палитры |
| `addons/`, `SpriteCook/` | сторонние инструменты |

`CLAUDE.md` — правила и законы симуляции для работы с Claude Code.

## Как открыть

1. Godot 4.7 (.NET-версия) → Import → эта папка.
2. Проект собирается под `Godot.NET.Sdk/4.7.2`, `net8.0` (`dotnet build Singulario.sln`
   или Build в редакторе).
3. Запуск — F5, главная сцена `Scenes/Main.tscn`.
