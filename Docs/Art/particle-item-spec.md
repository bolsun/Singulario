# Визуальная спецификация: частица-осколок и атом-предмет-шар

Автор: художник · утверждено пользователем 2026-10-01.
Концепты: https://claude.ai/artifact/AX4jHxC4Z1grNKxXGrct3C (выбран «Осколок»).

## Решение
- **Частица** — осколок: неправильный гранёный камешек, остаток материи схлопнувшейся вселенной.
  Раньше частица была шаром и путалась с центром атома.
- **Атом-предмет** (атом в дырке, T007) — прежний шар частицы, **без выреза центра**. Шар = маленький
  атом: по смыслу совпадает с центром атома, от осколка-частицы отличается формой.
- Читаемость: осколок (углы) — материал; шар (круг) — атом любого размера.

## Что сделать в коде (задача для ведущего программиста)
Сейчас частицы и предметы — один MultiMesh чанка с одной текстурой (`ParticleSpritePath`), предмет
отличается `INSTANCE_CUSTOM.w = 1` (шейдер вырезает центр). До задачи предмет рисуется осколком с
вырезом — временно.
1. Предмет рисуется спрайтом `atom_item_gray_16px.png`, вырез центра для него выключить.
   Дешёвый путь (на усмотрение программиста): текстура-атлас 32×16 (осколок | шар), шейдер палитр
   при `v_item` берёт правую половину — без второго MultiMesh.
2. Эффекты, где предмет показан «кружком цвета тира с тёмной серединой» (`OnItemTaken` у звезды,
   `OnItemAbsorbed` у ЧД), — тот же шар без выреза.
3. Атом-предмет в UI/инвентаре, если где-то рисуется кольцом, — шар.

## Сравнение со старым шаром
Прежние спрайты частицы сохранены: `particle_ball_gray_16px.png` / `_8px` / `_4px` (16 px совпадает с
`atom_item_gray_16px.png`). В задаче — отладочный переключатель «осколок ↔ шар» для частиц в дырках и в
месторождении (как F6 у звезды, не сохраняется), чтобы сравнить в игре. После решения переключатель и
лишние файлы можно убрать.
