# Типы звёзд — визуальная спецификация

Основа — GDD, «Производство → Роли звёзд» (2026-10-01). Механика — задача ведущего программиста.
Вид звезды — шейдер T017 (`star_assembler.gdshader`), его не меняем: меняются только размер и параметры по типу.

## Решения пользователя (2026-10-01)

- У звёзд больше нет тиров. **Цвет звезды — её тип, тип задаёт размер.** Цвет атома по-прежнему означает тир.
- **Ж — жёлтый карлик, печь 2×2.** Рецепт не выбирается, печь определяет его сама по входу:
  8 частиц Ж → атом Ж; атом Ж + 8 частиц К → атом К; атом Ж + 8 частиц С → атом С.
  Скорость прежняя, как у сборщика Ж (256 тиков).
- **К — красный гигант, фабрика 3×3** (нынешняя звезда-сборщик). Рецепт выбирает игрок.
  Рецепты: звезда Ж, звезда К, звезда С (составы К и С задаёт геймдизайнер).
- **С — синий сверхгигант, 6×6.** Пока ничего не делает: ставится и стоит (заготовка станции комет).
- Планета (1 клетка, сундук) — пока не делаем.

## Размеры и пропорции

Пропорции нынешней звезды 3×3 сохраняются для всех типов: тело занимает 0,733 стороны следа, корона в 2 раза больше тела.

| Тип | След | Тело, клеток | Квад с короной | Прогиб сетки |
|---|---|---|---|---|
| Ж карлик | 2×2 | 1,5 | 3 | 0,08 |
| К гигант | 3×3 | 2,2 (как сейчас) | 4,4 | 0,12 (как сейчас) |
| С сверхгигант | 6×6 | 4,4 | 8,8 | 0,2 |

- `BodyDiameterCells` и `StarWarp` задаются по типу (таблица в коде вместо одного числа).
  Прогиб С (0,2) остаётся меньше, чем у ЧД (0,25), потому что ЧД — главный центр притяжения взгляда.
- Арт-пиксель — по-прежнему 1 пиксель мира, при отдалении ступенями 2^n. У С рисунок просто крупнее.
- Свечение звезды (`GlowLayer`, пятно звезды) масштабируется по стороне следа, центр — центр следа.
- Порог упрощённого вида `StarLodZoom` один на всех; упрощённый диск — того же диаметра тела, что в таблице.

## Цвет

- Рампы — нынешние `TierTones` (тоны 0–4 Singulario 32), только теперь индекс означает тип: Ж — жёлтая, К — красная,
  С — синяя. Новых цветов нет.
- `TierSeeds` по типу оставить (разный рисунок короны у типов).

## Состояния

Как в T017 (работает / простаивает / выход забит, шеврон, дуга `#d23a4a`). Отличия по типам:

- **Печь Ж:** значка выбранного рецепта нет. Во время работы показывается значок того, что печь делает сейчас
  (атом тира результата). Пока печь простаивает, значка нет. Дуга прогресса — как у всех.
- **Фабрика К:** без изменений (значок рецепта, дуга, буфер).
- **Сверхгигант С:** всегда в состоянии «простаивает» (фаза 0, на тон темнее, без короны). Значка, дуги и шеврона нет.
  Если хочется, чтобы С не выглядел сломанным, можно отдельно утвердить корону в «работе» без дуги. Сейчас этого нет.

## Выход у чётного следа (2×2, 6×6)

У чётной стороны нет средней клетки. Клетку выхода выбирает ведущий программист (правило одно для всех чётных размеров).
Шеврон и рамка клетки выхода рисуются на той клетке, которую выберет код. Вид не меняется.

## Панель и инвентарь

- Кнопки ★Ж/★К/★С остаются, теперь это типы. Превью установки — след своего размера, центр под курсором
  (у 2×2 и 6×6 — ближайший угол клетки, как решит код).
- Звезда-предмет в выходном буфере и инвентаре — значок цвета типа, как сейчас.
