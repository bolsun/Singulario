# T033 — перекрёсток: дырки на всех портах, без дорожки, шеврон тира между телом и дыркой, красный пульс затора

Модель: Sonnet · effort: medium
Ветка: `feature/crossroad-view-fixes` от `experimental`.
Зависимости: T032 влита (механика «тик-так» уже в коде). Не запускать параллельно с задачами, правящими `Crossroad.cs`,
`CrossroadLayer.cs`, `UpdateCrossroadVisuals`, `StarLayer` (шеврон, пульс).

## Цель
Поправки вида перекрёстка — `Docs/Art/crossroad-visual-spec.md`, редакция 2026-10-02 (коммит `ef5569b`), GDD «Элементы набора →
Перекрёсток» (https://claude.ai/code/artifact/9cf8f132-726d-4cf1-b623-86551e34a7c4). **Механика не меняется** — всё из GDD
(2 позиции на оси, P = 8T / дырки, противофаза E–W/N–S с `Touch` в обоих режимах, постоянные выходы, R по часовой, вход только
принимает / выход только отдаёт, `CrossOutputs` в сохранении, старые сохранения → E,S) сделано в T032 и проверено самопроверкой.

Меняем только вид:
1. **Дырки на всех 4 портах** — и на входах, и на выходах (в дырке выхода стоит частица, ждущая соседа).
2. **Дорожку «+» убрать.**
3. **Шеврон выхода — всегда, между телом и дыркой выхода** (дырку не заменяет): центр — посередине между краем тела и краем
   дырки, `(BodyRadius + OrbitRadius − HoleRadius) / 2` (при клетке 96: (16 + 40) / 2 ≈ 28 px от центра атома); высота ≈ 8,
   полуширина ≈ 8, линия 2 px; форма — как у звезды, остриём наружу. **Цвет — тир атома, тон 3**.
4. **Выход забит — красный пульс шеврона, как у звезды** (`ChevronPulse`, `ChevronStepTicks`). Только вид.

## Решения ведущего программиста (обязательны для исполнителя)
- **Размеры — от радиусов, не числами.** Центр шеврона — формула выше от `BodyRadius`, `OrbitRadius`, `HoleRadius`;
  `ChevronHeight`/`ChevronHalfWidth` = 8 по умолчанию (`[Export]` остаются).
- **Цвет тона 3.** Ж/К/С — `ffc93c` / `ff6e5e` / `69b8ff` (тон 3 рампы тира, как дуга звезды). Серое — `cfcde0` («Серое 3»,
  предпоследний тон серой рампы `Resources/palettes/singulario-32.gpl`, по аналогии с тоном 3 цветных). Таблицу держать в
  `CrossroadLayer` `[Export] Color[] ChevronTierColors` (4 цвета, Ж/К/С/серое) — художник сможет поправить без кода.
  `ChevronColor` (`#4d4268`) и `TrackColor`/`TrackWidth` дорожки — удалить (ширину линии шеврона оставить отдельным полем).
- **Пульс — общий со звездой, без копий.** Сделать `StarLayer.ChevronPulse` публичным статическим (`internal`/`public static
  readonly`) и брать оттуда. Шаг — `ChevronStepTicks`: взять с узла `StarLayer` (`../StarLayer`, как в `NucleusLayer`), если
  узла нет — 24. Индекс ступени — `GlobalTick / step % ChevronPulse.Length`, как у звезды: на паузе пульс стоит.
- **«Забит» — по GDD/спецификации:** переворот оси не состоялся, потому что выход занят (на входе есть частица), и так
  **не меньше одного периода P** — т. е. со второго подряд несостоявшегося переворота. Обычное ожидание соседа — не затор.
  Отсчёт — поле **только для вида** в `Crossroad`, по образцу `OutFreedTick` (в хеш, сохранение и законы не входит):
  `long[] BlockedSince = new long[2]` (−1 — не забит):
  - `Flip(axis, tick)`: если `Has(input) && Has(output)` — `BlockedSince[axis]` = `tick`, если было −1; иначе (переворот
    состоялся или вход пуст) — −1;
  - `TakeOut(side, tick)` — −1 для оси стороны (выход освободился — затора больше нет, не ждать следующего события);
  - `RotateOutputs` — −1 у обеих осей; `Clear` и конструктор — −1.
  Вид: ось забита, если `BlockedSince[axis] >= 0 && GlobalTick − BlockedSince[axis] >= P` (`CrossPeriod(n)`).
  Новое состояние в `Flip`/`TakeOut` не влияет на передачу; законы класса не трогать, только добавить поле и комментарий.
- **Данные для рисования.** `NucleusLayer.Crossroads()` отдаёт сейчас `(center, exitMask)`; расширить до
  `(center, exitMask, tier, blockedMask)` — `blockedMask` — биты сторон-выходов забитых осей (считается здесь, тик и P есть только
  у `NucleusLayer`). Только чтение.
- **Дырки.** `UpdateCrossroadVisuals`: 4 инстанса дырок на N/E/S/W всегда (убрать пропуск выходов). Частицы — без изменений
  (частица выхода стоит в дырке выхода, частица входа едет поверх шеврона — это нормально по спецификации).

## Риски
- Ложный пульс на 8 дырках (P = T): сосед с совпадающей фазой может забирать на границе периода. Порог «≥ P со второго
  несостоявшегося переворота» это гасит; если в игре пульс мигает на нормальной линии — сообщить, порог не подбирать молча.
- Серый тон 3 (`cfcde0`) — решение по аналогии, художник может поменять в `ChevronTierColors`.
- Читаемость шеврона тона 3 на ярком ореоле свечения (L) — проверить глазами с вкл/выкл свечением, отметить в отчёте.
