# T009 — Новая игра: закрытая территория, стартовая зона 2×2, обломки, правило месторождений

Статус: поставлена.

Ветка: `feature/start-territory` от `experimental`
(`git checkout -b feature/start-territory experimental`). После отчёта — влить в `experimental`
(CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: GDD — «Прогрессия → Старт» (обновлён 30.09), «Законы → Правила передачи»
(месторождение отдаёт своему тиру и серым), «Производство → Выходной буфер и инвентарь».
Словарь: «ядро» в дизайне = атом (в коде Nucleus/`NucleusEntity`); месторождения/источники —
`EnergyClusterLayer`.

## Цель
Первая часть кор-геймплея: в настоящем режиме (не песочнице) игра начинается с маленькой
открытой зоны, в которой лежат останки вселенной — источники Ж, разорванная цепочка и
свободные атомы. Задания и расширение — следующая задача (T010).

## Что сделать

### 1. Открытая и закрытая территория
- Набор открытых чанков — чистые данные в одном месте, сохраняется.
- В настоящем режиме открыты только стартовые 2×2 чанка вокруг начала координат
  (чанки (-1,-1), (0,-1), (-1,0), (0,0)).
- Закрытые чанки: видны затемнёнными (как «туман»), содержимое не показывается, ставить
  и удалять ничего нельзя (красная подсветка), бросок и перенос в закрытый чанк не проходят.
- Функция «открыть чанки» (понадобится T010) — есть и проверена хотя бы вручную (например,
  отладочной клавишей).
- В песочнице вся карта открыта, как сейчас.

### 2. Новая игра и стартовая зона
- Кнопка «Новая игра» (рядом с Экспорт/Импорт): очищает поле, включает настоящий режим,
  обнуляет инвентарь и генерирует стартовую зону. Раскладка фиксированная (шаблон), без
  случайности — или со случайностью только с явным seed.
- Стартовая зона:
  - ЧД 4×4 в центре, на пересечении четырёх чанков (центр ЧД — начало координат);
  - в одном из чанков — не меньше 4 источников Ж в ряд (чтобы заполнить одну сторону линии
    атомов), запас каждого — настройка, с хорошим запасом на первое задание;
  - разорванная цепочка рабочих атомов Ж от источников к горизонту ЧД с 2–4 пропусками;
  - несколько свободных атомов Ж (обломки) рядом, ровно столько, сколько нужно закрыть
    пропуски, плюс 1–2 запасных.

### 3. Обломки
- Свободный атом-обломок не работает (использовать замороженное состояние «груз»
  `IsCargo` — оно уже умеет «лежит и не работает»; вид — приглушённый).
- ПКМ по обломку — забрать в инвентарь (в настоящем режиме). ЛКМ по нему ничего не делает
  (активировать на месте нельзя — только забрать и поставить).
- В сохранении обломки сохраняются как сейчас груз.

### 4. Месторождение отдаёт только своему тиру и серым
- Источник частиц тира X отдаёт частицу только атому тира X или серому. Настройка-флаг,
  по умолчанию включён, в обоих режимах.
- Перенос частиц между атомами не меняется (материал на перенос не влияет).

### 5. Сохранение/загрузка
- Открытые чанки. Старые сохранения загружаются (всё открыто, как раньше).

## Не входит
Задания, прогресс ЧД, расширение по награде, открытие рецептов (T010/T011). Туман как красивая
графика — достаточно затемнения. Тесты производительности и долгие прогоны не делать
(прототип: сборка + короткая ручная проверка).

## Критерии готовности
- [ ] Сборка без ошибок и новых предупреждений.
- [ ] «Новая игра» даёт открытые 2×2 чанка, ЧД в центре, источники Ж, разорванную цепочку и
      обломки; остальное затемнено и недоступно.
- [ ] ПКМ по обломку кладёт атом в инвентарь, им можно закрыть пропуск; после этого ЧД
      получает частицы Ж, счётчик растёт.
- [ ] Атом К рядом с источником Ж частицы не берёт, серый — берёт.
- [ ] Песочница работает как раньше (всё открыто).
- [ ] Экспорт → Импорт сохраняет открытые чанки; старые сохранения загружаются.
