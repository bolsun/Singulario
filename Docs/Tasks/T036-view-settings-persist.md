# T036 — настройки вида сохраняются между запусками: F5, L, F4

Модель: Sonnet · effort: low
Ветка: прямо в `experimental` (маленькая задача).
Зависимости: нет. С T035 файлы не пересекаются — можно параллельно.

## Цель
GDD, раздел «Интерфейс» → «Настройки вида сохраняются между запусками» (решено 2026-10-02,
https://claude.ai/code/artifact/9cf8f132-726d-4cf1-b623-86551e34a7c4). Перед кодом прочитать раздел; расхождение — спросить.

Сохранять в `user://settings.cfg` (`Settings.cs`), как `grid_warp` (T019):
- F5 — `NebulaBackground.SoftLight` → ключ `soft_light` (по умолчанию `false` — дизеринг);
- L — `GlowLayer.Enabled` → ключ `glow` (по умолчанию `true`);
- F4 — вариант фона `NebulaBackground._variant` → ключ `nebula_variant`, **по имени варианта** (строка из `Variants[i].name`,
  не индекс — порядок списка может меняться); неизвестное имя — вариант по умолчанию (0).
F6 (звезда спрайт/шейдер) и F7 (месторождение) не сохранять — отладочные. Меню настроек не трогать.

## Решения ведущего программиста
- `Settings`: три статических поля рядом с `GridWarp`, чтение в `Load`, запись в `Save` — тем же образцом.
- `NebulaBackground._Ready` — начальные значения из `Settings` (после `Settings.Load`, который уже вызывается при старте — проверить
  порядок); `[Export]` значения по умолчанию остаются значениями по умолчанию `Settings`.
- Нажатие F4/F5/L — поменять поле `Settings` и вызвать `Settings.Save()` сразу (как Shift+G).
- Если `GlowLayer` создаётся после `NebulaBackground._Ready` — применить `Enabled` при создании.
