Статус: выполнена (ветка `feature/goals-expansion`, влита в `experimental`). Проверено: сборка
без ошибок и предупреждений; короткий прогон без окна (временный скрипт, не в репозитории):
новая игра → 4 этапа через счётчики ЧД, кольца 4 → 16 → 36 → 64 → 100 чанков, шаблоны наград
в новых кольцах, рецепты, крафт звезды-предмета и списание из инвентаря, экспорт → импорт
(этап, прогресс, рецепты, seed, звёзды), старые сохранения. В окне игры не проверялось.
Решения: поле С — награда этапа 3 (чтобы этап 4 было чем проходить); ПКМ по звезде в
настоящем режиме возвращает звезду и её выходной буфер; звезда с закрытым рецептом работает,
но выбрать закрытый рецепт по ЛКМ нельзя; P — засчитать текущий этап (отладка).

Ветка: `feature/goals-expansion` от `experimental`
(`git checkout -b feature/goals-expansion experimental`). После отчёта — влить в `experimental`
(CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: GDD — «Прогрессия → Старт» (таблица этапов, «Задания ЧД и расширение»,
«Шаблоны чанков»), «Производство → Звезда — сборщик», «План выпуска».
Опирается на T009: территория (`Territory`, «открыть чанки»), JSON-шаблоны чанков и функция
«поставить шаблон с чанка (cx, cy)», «Новая игра».
Словарь: «ядро» в дизайне = атом (в коде Nucleus/`NucleusEntity`).

## Цель
Замкнуть кор-цикл: ЧД показывает, чего ждёт; игрок выполняет задание; вселенная расширяется
кольцом чанков и даёт награду — новые шаблоны на карте и открытые рецепты.

## Что сделать

### 1. Цепочка заданий — данные
- Задания — данные в одном месте (JSON-файл в `res://Data/`, например `goals.json`), не код.
  У этапа:
  - требование: список пунктов «частицы цвета X × N» или «атомы тира X × N» (пока хватит
    одного пункта, но формат — список);
  - награда: расширение (кольцо), список шаблонов для размещения в новом кольце, список
    открываемых рецептов.
- Первые этапы (N — малые числа для тестов, правятся в JSON):

| Этап | Требование | Награда |
| --- | --- | --- |
| 1 | 64 частицы Ж | кольцо (2×2 → 4×4); шаблон «звезда Ж + источники Ж + 3 свободных атома»; рецепт «атом Ж» |
| 2 | 8 атомов Ж | кольцо (→ 6×6); шаблон «поле К: источники К + свободные атомы К»; рецепт «звезда Ж» |
| 3 | 64 частицы К | кольцо; рецепт «атом К» |
| 4 | 64 частицы С | кольцо; рецепт «атом С» (шаблон поля С — во время этапа 3) |

  Шаблоны для наград — сделать простые заглушки в песочнице через экспорт из T009; пользователь
  потом перерисует их сам.

### 2. Прогресс
- Прогресс считается от ЧД с момента начала этапа (частицы по цветам, атомы по тиру — счётчики
  уже есть). Засчитывается только то, что нужно заданию; лишнее ЧД принимает как обычно.
- HUD: текст задания и полоска («Частицы Ж: 40 / 64»). Сектора диска ЧД — не в этой задаче.
- Все этапы пройдены — HUD так и пишет; ЧД продолжает принимать.

### 3. Расширение
- Этап выполнен → открывается следующее кольцо чанков вокруг открытой зоны (2×2 → 4×4 → 6×6 …).
- Шаблоны награды ставятся в случайные чанки нового кольца: seed явный (сохраняется), шаблоны
  не пересекаются друг с другом и с занятым (если места нет — сообщение в лог, шаблон пропускается).
- Короткий визуальный отклик на расширение (например, вспышка ЧД и плавное снятие затемнения) —
  на выбор в плане, коротко.

### 4. Открытие рецептов
- Набор открытых рецептов — данные, сохраняется. В настоящем режиме звезда показывает и
  перебирает по ЛКМ только открытые рецепты; в песочнице — все.
- Новая игра: открытых рецептов нет (первая звезда появляется вместе с рецептом «атом Ж»).
- **Рецепт «звезда Ж»** (новый): ингредиенты — атомы Ж, число — настройка в таблице рецептов,
  умеренное (например, 8). Результат — звезда-предмет: в линию не выдаётся (звезда 3×3 не едет
  по дыркам), только в выходной буфер; игрок забирает её Ctrl/Shift+клик. В настоящем режиме
  установка звезды тратит звезду нужного тира из инвентаря; в песочнице — бесплатно.

### 5. Сохранение/загрузка
- Номер этапа, прогресс, открытые рецепты, seed, звёзды в инвентаре. Старые сохранения
  загружаются (этап 1, рецепты — все открыты для старых песочничных сохранений).

## Не входит
Сектора на диске ЧД, задания на темп и смесь, красивый ролик расширения, туманная графика,
рецепты К/С-звёзд, вращателей и серых атомов. Тесты производительности и долгие прогоны не
делать (прототип: сборка + короткая ручная проверка).
