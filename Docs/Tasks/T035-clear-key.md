# T035 — очистка C: содержимое объекта под курсором

Модель: Sonnet · effort: high
Ветка: `feature/clear-key` от `experimental`.
Зависимости: T033, T034 влиты. Не запускать параллельно с задачами, правящими `RefundToInventory`, `Crossroad.cs`, `StarSet.cs`,
`RemoveHoldLayer.cs`, `ControlHints`/`HintLabel`. С T036 (настройки вида) файлы не пересекаются — можно параллельно.

## Цель
GDD, раздел «Интерфейс» → «Очистка C» (решено 2026-10-02, https://claude.ai/code/artifact/9cf8f132-726d-4cf1-b623-86551e34a7c4).
Перед кодом прочитать этот раздел; если он расходится с задачей — остановиться и спросить.

Клавиша **C** очищает содержимое объекта под курсором:
- атом Ж/К/С/серый (обычный режим) — все дырки кольца;
- перекрёсток — все 4 стороны; режим перекрёстка и `OutRot` остаются;
- звезда — входной буфер и текущая работа (`ActiveRecipe`, `Elapsed`); **выходной буфер `Output` не трогать**; рецепт фабрики и
  сторона выхода остаются;
- ЧД, источник, обломок (груз), пустая клетка — ничего (без отклика).

Частицы сгорают; атомы-предметы в настоящем режиме — в инвентарь (как `RefundItemsToInventory`), в песочнице сгорают.
Бесплатно, сразу (без удержания), в обоих режимах. Зажатая C с движением мыши — протяжка по клеткам (каждая клетка — один раз за
нажатие). Отклик — короткая вспышка следа объекта.

## Решения ведущего программиста (обязательны для исполнителя)
- **Законы — в чистом классе, не в `NucleusLayer`.**
  - `Crossroad.ClearContents()` — сбросить стороны, `OccupiedMask`, вид-поля (`BlockedSince`, `EnterTick`/`OutFreedTick` — как
    в существующем `Clear`); `OutRot` не трогать. Если существующий `Clear` уже делает ровно это — использовать его, новый не
    заводить.
  - `Star.ClearInput()` — то же, что приватный `Burn()` (буфер, `ActiveRecipe`, `Elapsed`); `Output`, `RecipeId`, сторона выхода —
    как были. Возвращает, были ли изменения. Атомы в буфере (ячейки атомов `StarCatalog.SlotOf`) — вызывающий до очистки
    забирает в инвентарь (настоящий режим); ингредиенты текущей работы уже потрачены — сгорают без возврата.
  - Кольцо атома — очистка слотов (частица/предмет → пустая дырка) рядом с существующими функциями кольца; блокировку
    «принято до поворота» снять вместе с содержимым.
- **`NucleusLayer.ClearAt(row, col)`** — одно место: находит объект (звезда по следу → атом в `_entAt`), пропускает обломок
  (`IsCargo`), вращатель/бросатель (заморожены — C их не трогает), ЧД, источник. Порядок: `RefundItemsToInventory` (у атома и
  перекрёстка уже умеет обе формы; для звезды — атомы буфера) → очистка → **`Touch`** атома и его 4 соседей (содержимое меняется в
  обход передачи; соседи могли стоять в заторе на полной дырке). Атом в полёте (`_claimed`/в пути) — если очистка там опасна,
  пропустить и написать в отчёте. Звезда: проверить, что приём (`FeedStarsFromNeighbors`) обходит звёзды каждый тик; если нет —
  `Touch` соседей по краю следа. Возвращает, было ли что очищать (для вспышки).
- **Ввод.** C — `_UnhandledInput`/`_Process` в `NucleusLayer` рядом с ПКМ-удалением; только слой 1, не в меню, не на паузе меню.
  Протяжка — запоминать последнюю клетку в нажатии, по образцу протяжки ЛКМ/ПКМ. Перед этим убедиться, что C свободна
  (`grep Key.C`) и не перехвачена камерой/панелью.
- **Вспышка.** Переиспользовать `RemoveHoldLayer.FlashDenied` (рамка следа): обобщить до `Flash(row, col, side, color)`,
  `FlashDenied` — обёртка с красным. Для C — нейтральный светлый цвет (`[Export] ClearFlashColor`, по умолчанию белый с альфой,
  как полоска удержания). Новых узлов и спрайтов не заводить.
- **Подсказка.** `ControlHints`: третья часть `ClearDone` («C — очистить»), засчитывается первым нажатием C над объектом с
  содержимым. Сохранение: `SavedHints.Clear` (нет поля — пройдена), новая игра — сброс. `HintLabel` — третья строка.
  Ключ «C — очистить» → `Data/Localization/en.po` («C — clear»).

## Риски
- Пропущенный `Touch` — режим по событиям разойдётся с полным обходом: очищенный атом не возьмёт новую частицу, сосед останется в
  заторе. Проверить Shift+F3 (полный обход) на том же поле — поведение одинаковое.
- `_claimed` на очищенной стороне в этом тике: очистка между тиками (ввод), эпоха `_claimed` новая — проверить, что занятость не
  переживает тик.
- Блокировка «принята до поворота» на очищенной дырке — не должна мешать приёму новой частицы.
