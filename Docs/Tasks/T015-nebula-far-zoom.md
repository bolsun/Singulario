# T015 — Дальний зум: чанки как туманности

Статус: выполнена (ветка `feature/nebula-lod`). Уточнения пользователя по ходу: источники
(месторождения) входят в состав чанка — клетка источника весит как атом, вес — настройка
`NebulaSourceWeight`; смешивание пятен — аддитивное.

Ветка: `feature/nebula-lod` от `experimental` (`git checkout -b feature/nebula-lod experimental`).
После отчёта — влить в `experimental` (CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: GDD «Визуал → Ступени детализации по зуму»; T014 (буферы MultiMesh, точки ниже
`AtomDotZoom`), `NucleusLayer.cs` (отрисовка чанков), `GridDraw` (сетка скрыта ниже 0.025).
Словарь: «ядро» в дизайне = атом (в коде Nucleus/`NucleusEntity`).

## Цель
Третья ступень детализации. Далеко — атомов нет: каждый чанк, где есть атомы, светится
мягким рассеивающимся пятном цвета преобладающего в нём тира, как туманность. Поверх —
звёзды и ЧД. Отрисовка сокращается до одного пятна на чанк, а дальний зум становится
заготовкой карты вселенной.

## Что сделать

### 1. Данные: состав чанка
- У каждого чанка — счётчики атомов по тиру, обновляются при постановке / удалении /
  переезде атома (не пересчитывать каждый кадр). Преобладающий тир — по наибольшему
  счётчику, при равенстве — детерминированно (например, меньший номер тира).
- Считать только рабочие атомы-переносчики и серые; обломки и заморожённые вращатели /
  бросатели — на выбор в плане (коротко).

### 2. Отрисовка туманностей
- Ниже порога `NebulaZoom` (настройка; подобрать так, чтобы чанк на экране был порядка
  десятков пикселей, например 0.05) атомы не рисуются вовсе (ни точки, ни кольца).
- Каждый непустой чанк — одно мягкое пятно: радиальный градиент с размытым краем, чуть больше
  чанка, чтобы соседние пятна сливались в облако. Цвет — цвет преобладающего тира (палитра
  тиров), яркость/непрозрачность растёт с числом атомов в чанке (до насыщения).
- Все пятна — один MultiMesh (или один проход), только видимые чанки.
- Плавный переход: в полосе зумов около `NebulaZoom` точки гаснут, пятна проявляются
  (без скачка).
- Звёзды и ЧД остаются видны поверх туманностей на любом зуме.

### 3. Производительность
- Ниже `NebulaZoom` отрисовка атомов не выполняется совсем (как будто чанки невидимы для
  атомного рендера); симуляция не меняется.

## Не входит
Минимальный экранный размер звёзд и ЧД, превращение ЧД в Сингулярность, отдельный вид
месторождений на дальнем зуме (в цвет и яркость пятна они входят — см. статус), туман закрытых чанков — отдельно. Тесты производительности и долгие прогоны не
делать (прототип: сборка + короткая ручная проверка; одно короткое сравнение мс отрисовки по F3
до/после на поле из случайного заполнения — достаточно).

## Критерии готовности
- [x] Сборка без ошибок и новых предупреждений.
- [x] При отдалении точки плавно сменяются мягкими пятнами цвета преобладающего тира;
      соседние пятна сливаются.
- [x] Звёзды и ЧД видны поверх.
- [x] По F3 на дальнем зуме мс отрисовки атомов около нуля.
- [x] Порог и ширина перехода — настройки.
- [x] Ветка влита в `experimental`.

## Итог
- Шаг 1: `ChunkComposition.cs` (чистые данные) — счётчики по тиру у чанка: рабочие атомы Ж/К/С и серые
  (перекрёстки — своего тира; обломки, вращатели, бросатели не считаются) и клетки источников.
  Преобладающий тир — наибольший вес, при равенстве меньший номер. Атомы чанка пересчитываются в
  `RebuildChunkMeshes` (через неё идёт любое изменение списка атомов чанка), источники — по
  `EnergyClusterLayer.CellsVersion` (новый счётчик: установка, стирание, исчерпание; `Version` для
  кандидатов захвата не тронут), только пока пятна видны.
- Шаг 2: `NebulaLayer.cs` — один MultiMesh (аддитивное смешивание), мягкое радиальное пятно на каждый
  непустой видимый чанк: размер `NebulaScale` (2 чанка), цвет тира, непрозрачность
  `NebulaMaxAlpha` × √(вес / `NebulaSaturation`). Узел — первый дочерний `NucleusLayer`: под чанками,
  звёздами и ЧД; на слое 2 скрыт вместе с ним.
- Шаг 3: ниже `NebulaZoom` (0,05; чанк ≈ 77 px) узлы чанков скрыты, `UpdateChunkVisuals` не вызывается.
  Полоса `NebulaZoom`…`NebulaZoom × NebulaFadeRatio` (0,05…0,08, лог-шкала): точки гаснут (свой материал
  точек, uniform `fade` в шейдере палитр), пятна проявляются. Бенч отрисовки прячет главное меню.
- Замер (`--render-bench`, поле 13×13 чанков, 21 649 атомов, окно 1152×648), зум 0,04: отрисовка атомов
  0,55 → 0,05 мс (видно атомов 18 259 → 0), кадр 6,5 → 6,6 мс. В полосе (0,065) — 0,43 мс.
- Сверка `--sim-selfcheck` (1 000 тиков) — совпадает; симуляция не менялась.
- Замечено, не исправлено: `--sim-selfcheck` идёт ~165 мс/тик (4 991 атом) и на `experimental` до T015
  (в отчёте T014 — единицы мс); вероятно, поток логов «переезд … отменён» (известный баг отката прибытия).
