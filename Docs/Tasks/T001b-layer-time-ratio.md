# T001b — Соотношение времени слоёв k как настройка (по умолчанию 1)

Статус: выполнено (ветка `experimental`).

Ветка: продолжаем в `experimental` (доработка T001).

## Проблема
В `MoleculeLayer.cs` соотношение времени слоёв зашито константой
`public const int L2TickRatio = 8`. Из-за этого Ж-молекула поворачивается раз в
256 тиков — на слое 2 всё выглядит в 8 раз медленнее, чем ядра на слое 1.
Хотим сравнить в прототипе два варианта: k = 1 (оба слоя на экране в одном темпе)
и k = 8 (как сейчас).

## Что сделать
1. Заменить константу `L2TickRatio` на настройку `[Export] public int L2TickRatio = 1;`
   (одно место истины). Допустимые значения — 1, 2, 4, 8; иное значение при запуске
   привести к ближайшему допустимому и написать предупреждение в лог.
2. Горячая клавиша для сравнения на лету (например, `K`): переключает k по кругу
   1 → 2 → 4 → 8 → 1. Текущее значение показывать в HUD рядом с «Слой 1/2»
   («k = 1»). Скачок фазы молекул при переключении допустим.
3. Проверить всё, что зависит от периода молекулы, и перевести на эту настройку:
   расчёт фазы, выравнивание паузы (если молекулы в нём участвуют), любые места,
   где подразумевалось 8. Периоды ядер слоя 1 (`TierTicks`, `_pauseAlignTicks`,
   `_energyCaptureTicks` в `NucleusLayer.cs`) НЕ трогать — это другие восьмёрки
   (8 позиций кольца), к k отношения не имеют.
4. k в сохранение НЕ записывать: это настройка прототипа, а не состояние мира.

## Критерии готовности
- [ ] По умолчанию (k = 1) Ж-молекула поворачивается с тем же периодом, что Ж-ядро
      (32 тика на фазу); К — 16, С — 8, серое — 4. Молекулы одного тира и направления
      синхронны.
- [ ] Клавиша переключает k, HUD показывает текущее значение; при k = 8 поведение
      совпадает с тем, что было до доработки.
- [ ] Поведение слоя 1 не изменилось.
- [ ] Проект собирается без ошибок.

## Порядок
Короткий план (какие места зависят от k) → подтверждение → правка → сборка → коммит.
