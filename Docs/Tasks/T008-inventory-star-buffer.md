# T008 — Инвентарь и выходной буфер звезды

Статус: **выполнена** (ветка `feature/inventory`, 30.09.2026).

Итог:
- Выходной буфер — очередь тиров `Star.Output` (FIFO), ёмкость `NucleusLayer.StarOutputCapacity`
  (10). Готовая работа уходит туда (`Star.TryFinishToOutput`), буфер полон — звезда стоит
  (красная дуга). `OutputStarsToHoles` отдаёт из головы очереди. Смена рецепта буфер не сжигает.
  При наведении — «в буфере: N / 10».
- Инвентарь — `Inventory.cs` (чистые данные: атомы Ж/К/С, режим), `NucleusLayer.Inventory`;
  строка в HUD — `InventoryLabel` (создаёт `FpsLabel`), вспыхивает цветом тира при пополнении.
- Ctrl+ЛКМ / Shift+ЛКМ по звезде — `StarLayer.TakeToInventory`; кольцо летит к курсору.
- Режим: клавиша **M**, настройка `NucleusLayer.SandboxMode` (по умолчанию песочница).
  Настоящий: установка Ж/К/С тратит атом, нет атома — красное превью и отказ; ПКМ
  (`RefundToInventory`) возвращает атом Ж/К/С и атомы-предметы из дырок любого снятого атома;
  замена атома зажатой ЛКМ = снять старый + поставить новый. Серые, вращатели, бросатели,
  звёзды, ЧД, источники — бесплатно (рецептов нет). Флага «оплачен» нет — решение пользователя.
- Сохранение: `Inventory`, `Sandbox` в корне JSON, `Output` у звезды; без полей — пустой
  инвентарь, режим из настройки, пустой буфер.

Ветка: `feature/inventory` от `experimental` (`git checkout -b feature/inventory experimental`).
После отчёта — влить в `experimental` (CLAUDE.md, «Процесс»). В `main` не пушить.

## Цель
Игрок получает построенные звездой атомы себе в инвентарь и строит из них. Звезда копит
готовое в выходном буфере, как сборочный автомат в Factorio.

## Что сделать

### 1. Выходной буфер звезды
- У звезды всегда есть выходной буфер на `StarOutputCapacity = 10` атомов (настройка).
- Готовый атом попадает в буфер. Из буфера звезда отдаёт атомы в дырку соседнего атома на
  стороне выхода, как сейчас (T007).
- Нет отводящего атома или линия не успевает — атомы копятся в буфере. Буфер полон — звезда
  стоит (затор, как сейчас).
- При наведении на звезду видно «в буфере: N / 10» (рядом с рецептом из T006b).

### 2. Инвентарь
- Инвентарь игрока — счётчики атомов по тиру (Ж / К / С; позже — другие предметы).
  Чистые данные в одном месте, без Godot.
- Показ в HUD: сколько атомов каждого тира в инвентаре.

### 3. Забрать из звезды
- **Ctrl+ЛКМ** по звезде — весь выходной буфер в инвентарь.
- **Shift+ЛКМ** по звезде — один атом.
- Обычный ЛКМ по звезде — смена рецепта, как сейчас.
- Короткий визуальный отклик (например, счётчик в HUD мигает или кольцо летит к курсору —
  на выбор в плане, коротко).

### 4. Песочница и настоящий режим
- Переключатель режима (настройка + горячая клавиша, какая — на выбор в плане; показывать
  режим в HUD). По умолчанию — песочница, чтобы прототип тестировался как раньше.
- **Песочница:** установка атомов бесплатная, как сейчас.
- **Настоящий режим:**
  - установка атома-переносчика Ж/К/С тратит 1 атом этого тира из инвентаря; нет атома —
    установка не делается (красная подсветка, как у запрета);
  - ПКМ по своему установленному атому-переносчику возвращает его в инвентарь; атомы-предметы
    из его дырок тоже уходят в инвентарь, частицы пропадают;
  - серые атомы, вращатели, бросатели, звёзды, ЧД, источники — пока бесплатно (рецептов у них
    нет), это указать в отчёте.

### 5. Сохранение/загрузка
- Инвентарь, режим, выходной буфер звёзд. Старые сохранения загружаются.

## Не входит
Обломки как источник атомов, планеты-хранилища и логистическая сеть, рецепты серых атомов,
вращателей и бросателей, окно инвентаря (достаточно строки в HUD). Тесты производительности
и долгие прогоны не делать (прототип: сборка + короткая ручная проверка).

## Критерии готовности
- [ ] Сборка без ошибок и новых предупреждений.
- [ ] Звезда без отводящего атома копит до 10 атомов и встаёт; с отводящим — отдаёт в линию.
- [ ] Ctrl+ЛКМ забирает весь буфер, Shift+ЛКМ — один атом; инвентарь в HUD растёт.
- [ ] Настоящий режим: установка тратит атом, без атома — запрет; ПКМ возвращает атом и
      предметы из его дырок.
- [ ] Песочница работает как раньше.
- [ ] Экспорт → Импорт восстанавливает инвентарь, режим и буферы; старые сохранения загружаются.
