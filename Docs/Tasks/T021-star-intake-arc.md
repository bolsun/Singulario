# T021 — Поглощение звездой по дуге (подхват по касательной)

Статус: поставлена.

Ветка: `fix/star-intake-arc` от `experimental` (`git checkout -b fix/star-intake-arc experimental`).
Маленькая задача. После отчёта — влить в `experimental` (CLAUDE.md, «Процесс»). В `main` не пушить.
Можно параллельно с T019 (прогиб сетки, `GridDraw`) — файлы не пересекаются.
Контекст: `Scripts/StarLayer.cs` — эффект поглощения (`IntakeFx`, отрисовка около строки 610:
сейчас прямая к центру с ускорением `e = t * t`, конец на `IntakeEndFraction` = 2/3 радиуса);
шейдер звезды из T017 (направление вращения короны). Эффект ЧД — `BlackHoleLayer.cs`, не трогать.

## Решение (пользователь + геймдизайнер + художник)
Два разных языка движения, чтобы «отдал в ЧД» и «накормил звезду» не путались:
- **ЧД** — как сейчас: спираль, затягивание, красное смещение. Не менять.
- **Звезда** — **короткая дуга подхвата**: объект подлетает по мягкой кривой примерно на
  четверть оборота вокруг центра звезды (не несколько витков), по касательной, и тонет на 2/3
  радиуса, как сейчас. Без красного смещения, без ускорения к центру (плавное замедление или
  равномерно — на выбор, чтобы выглядело мягко).

## Что сделать
- Угол объекта относительно центра звезды меняется на `IntakeArcTurns` оборота за время
  поглощения (настройка, по умолчанию 0.25), радиус — от начального до 2/3 радиуса диска.
- **Направление дуги** (уточнение художника): у короны T017 нет вращения, но поверхность звезды
  дрейфует в одну сторону (сдвиг ячеек в шейдере). Направление дуги берётся из этого дрейфа —
  одинаково у всех звёзд, без случайности. Отдельный «спин» звезде не придумывать.
- **Скорость ровная**, без ускорения; длительность — как сейчас (`IntakeSeconds` = 0,4 с).
- **Дуга не выходит за корону звезды**: летящий объект не должен залезать на соседние клетки
  (при необходимости начальная точка дуги прижимается внутрь короны).
- **Вспышки при касании нет** (при сотнях частиц это шум; звезда спокойнее потока). Возможная
  едва заметная ступень свечения только на прибытие атома-предмета — не в этой задаче.
- Растворение в конце, размер частиц/предметов, цвета — как сейчас.
- Всё остальное в эффекте (лимит, вне экрана не обновляется) — без изменений.
- Языки движения записаны в арт-библии, раздел «Эффекты событий».

## Не входит
Эффект ЧД, логика звезды (поглощение в симуляции по-прежнему мгновенное). Тесты
производительности не делать (прототип: сборка + короткая ручная проверка).

## Критерии готовности
- [ ] Сборка без ошибок и новых предупреждений.
- [ ] Частицы и атомы-предметы подлетают к звезде по дуге ~¼ оборота и тонут на 2/3 радиуса;
      направление совпадает с вращением короны.
- [ ] Эффект ЧД не изменился.
- [ ] Ветка влита в `experimental`.
