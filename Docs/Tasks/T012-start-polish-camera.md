# T012 — Старт: атомы на 8 дырок, камера на старте и при расширении, подсказки управления

Статус: поставлена.

Ветка: `feature/start-polish` от `experimental`
(`git checkout -b feature/start-polish experimental`). После отчёта — влить в `experimental`
(CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: T009 (новая игра, стартовая зона, шаблоны), T011 (расширение, снятие тумана),
`CameraController.cs`, HUD. Словарь: «ядро» в дизайне = атом (в коде Nucleus/`NucleusEntity`).

## 1. Атомы по умолчанию — 8 дырок
- Решение GDD: ёмкость любого атома — 8 дырок, режим 2/4 — выбор игрока.
- Сейчас на старте у игрока атомы с 4 дырками. Надо, чтобы по умолчанию везде было 8:
  атомы стартового шаблона (`start_zone.json`) и шаблонов наград, выбор на панели по умолчанию,
  установка атома из инвентаря (Ж/К/С), обломки.
- Режимы 2 и 4 остаются доступны игроку, как сейчас.

## 2. Камера на старте
- После «Новой игры» камера стоит так, чтобы были видны все 4 стартовых чанка (с небольшим
  полем по краям), с учётом размера окна.

## 3. Показ расширения камерой
- При расширении вселенной камера плавно летит в центр (начало координат) и отдаляется так,
  чтобы новая открытая область целиком была на экране; затем снимается туман (T011) — порядок:
  камера долетела → туман снимается → вспышка ЧД.
- Так — только для первых `ExpansionCameraShows = 4` расширений (настройка); дальше расширение
  без движения камеры.
- Длительность полёта — настройка (порядка 1–1,5 с), плавная кривая.
- Во время полёта ввод камеры игнорируется; после — камера остаётся на общем виде, игрок
  двигает её сам.

## 4. Подсказка управления
- После «Новой игры» внизу по центру экрана надпись: «W, A, S, D — перемещение камеры,
  G — сетка» (можно разбить на две строки/пункта).
- Каждая часть исчезает, когда игрок её выполнил: подвинул камеру (WASD) — пропадает первая;
  включил или выключил сетку (G) — вторая. Когда выполнено всё — надпись исчезает целиком.
- Состояние «подсказка пройдена» сохраняется вместе с игрой.
- Строки — через механизм перевода Godot (`Tr(...)`), чтобы T013 добавила английский без правки кода.

## Не входит
Меню, пауза, язык, автосохранение (T013). Тесты производительности и долгие прогоны не делать
(прототип: сборка + короткая ручная проверка).

## Критерии готовности
- [ ] Сборка без ошибок и новых предупреждений.
- [ ] Новая игра: все атомы и обломки — на 8 дырок, из инвентаря ставятся атомы на 8.
- [ ] Новая игра: камера показывает все 4 стартовых чанка.
- [ ] Первые 4 расширения: камера летит в центр и отдаляется до всей области, потом снимается туман;
      пятое — без полёта.
- [ ] Подсказка появляется на старте и исчезает по частям после WASD и G.
- [ ] Ветка влита в `experimental`.
