## Цель
Установленный атом светится своим тиром; ореолы соседей сливаются в видимую дорожку линии. Звёзды и ЧД светят
сильнее, Сингулярность на отдалении — сильно. Два режима света — дизеринг и мягкий свет, один переключатель на
весь свет игры (фон + свечение).

## Решения пользователя
- Яркость — настройки. Порядок силы: **атомы — слабо, серые — очень слабо, звёзды — средне, ЧД — средне,
  Сингулярность (ЧД на дальнем зуме) — сильно.** Звёзды заметно ярче атомов.
- F8 — свечение вкл/выкл (для сравнения). F5 — режим света для всего (сейчас только фон).

## Что сделать

### 1. Буфер света
- Отдельный буфер (например, `SubViewport`) в разрешении клетки дизеринга: 1 пиксель буфера = `DitherPixel`
  пикселей экрана; сдвиг буфера привязан к миру, как узор фона (T016) — узор не рябит при зуме и едет с полем.
- Источники рисуют в буфер мягкие радиальные пятна (сложение), все — MultiMesh, без узлов на объект.
- Тиры копятся раздельно по каналам: R — Ж, G — К, B — С, A — серое (З — позже). ЧД/Сингулярность — отдельно
  (своя рампа), способ — на выбор в плане (второй буфер или отдельный проход для немногих ЧД).

### 2. Финальный проход
- Для пикселя: преобладающий тир, яркость = сумма с ограничением сверху (`GlowClamp`) — плотная застройка не
  выгорает в пятно.
- Цвет — тона рампы тира Singulario 32 (тон 0 — самый тёмный). **Дизеринг:** ступени + Байер 4×4, как у фона.
  **Мягкий свет:** плавная интерполяция по тем же тонам (буфер растягивается со сглаживанием). Свет не темнее
  фона под ним (смешение «светлее из двух» или сложение с ограничением — на выбор).
- Порядок слоёв: фон → свет → сетка → объекты.

### 3. Источники и сила (все — настройки)
| Источник | Радиус (стартово) | Тона (макс.) | Когда | Сила |
|---|---|---|---|---|
| Атом Ж/К/С | ~0,7 клетки | 0–1 | только рабочий (не обломок `IsCargo`) | слабо |
| Серый атом | ~0,7 клетки | 0 | рабочий | очень слабо |
| Звезда | ~2,5 клетки | 0–2 | работает — ярче, мягко «дышит» синхронно с фазой тира (T017); простаивает — гаснет; выход забит — ровно, без дыхания | средне |
| ЧД | ~3 клетки | тёплые тона диска: `#5e2a1e` → `#a8501c` → `#e8911f` | всегда | средне |
| Сингулярность | растёт при отдалении | к `#8a2d9e` → `#ff7ae0` → `#ffffff` (акцент палитры) | ЧД при зуме ниже `SingularityZoom` (плавный переход, в лог-шкале) | сильно |
- Сингулярность — это только усиление света ЧД на отдалении: радиус и сила растут, рампа уходит в акцентную;
  держит заметный размер на экране (минимум в пикселях экрана — настройка), чтобы центр вселенной читался на любом
  зуме. «Выворачивание» ЧД в белую дыру и иконки — не в этой задаче.
- Зум: на ступени «атом — точка» (`AtomDotZoom`) ореолы атомов остаются (фабрика читается светящимися линиями);
  ниже `NebulaZoom` (T015) ореолы атомов гаснут, звёзды и ЧД/Сингулярность светят.

### 4. Клавиши
- **F5** — «Дизеринг» ↔ «Мягкий свет» для фона и свечения вместе (одно состояние; надпись как сейчас).
- **F8** — свечение вкл/выкл, короткая надпись; строки — ключами в `Data/Localization/en.po`. Не сохраняется,
  по умолчанию вкл.

## Не входит
Свет звёзд на туманность, секторы диска ЧД по заданиям, вспышки событий, тир З, выворачивание ЧД в белую дыру,
закрытая территория. Производительность — устройством кода (маленький буфер, MultiMesh, один проход), без замеров.

## Критерии готовности
- [ ] Сборка без ошибок и новых предупреждений.
- [ ] Рабочие атомы светятся тиром, соседи дают дорожку; обломки не светятся; серые — едва.
- [ ] Звёзды ярче атомов, состояния звезды видны в свете; ЧД светит тёплым; на отдалении — сильная Сингулярность.
- [ ] Плотная застройка не выгорает (ограничение яркости).
- [ ] Дизеринг не рябит при панорамировании и зуме; мягкий режим плавный.
- [ ] F5 переключает весь свет, F8 — свечение; все силы и радиусы — настройки.
