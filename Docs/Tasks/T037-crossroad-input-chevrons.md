# T037 — перекрёсток: серые шевроны входа остриём внутрь

Модель: Sonnet · effort: low
Ветка: прямо в `experimental` (маленькая задача, только вид).
Зависимости: T033 влита. Не запускать параллельно с задачами, правящими `CrossroadLayer.cs`.

## Цель
`Docs/Art/crossroad-visual-spec.md`, «Шеврон входа» (2026-10-02): без шевронов на входах перекрёсток выглядит кособоко.
Добавить на двух сторонах входа шеврон той же формы, что у выхода, но остриём **внутрь** (к телу) — крест читается как
сквозной поток вход → центр → выход. **Механика и передача не меняются.**

## Что сделать
1. `CrossroadLayer._Draw`: в том же цикле по `Layer.Crossroads()` рисовать шеврон на сторонах входа —
   `inputMask = ~exitMask & 0xF` (у перекрёстка ровно два выхода, остальные две стороны — входы, это `InputSide` по `OutRot`).
   Центр — то же `at` от центра атома, что у выхода; тот же `DrawChevron` с теми же `ChevronHeight`/`ChevronHalfWidth`/
   `ChevronLineWidth`; остриё внутрь — передать направление `-dir` (точка ставится по `dir`, остриё смотрит к телу).
2. Цвет — новая настройка `[Export] public Color InputChevronColor` в `CrossroadLayer`, по умолчанию тон дырки `#372d4d`.
   Без тира, без пульса (затор входа не подсвечивается).
3. При R (`RotateOutputs`) шевроны входа поворачиваются вместе с выходами — получается само, т.к. маска берётся из `exitMask`
   каждый кадр; отдельного кода не нужно.
4. Шеврон выхода, его цвет тира и красный пульс — **не менять**. Порог видимости (`HoleHideZoom`/`AtomDotZoom`) — общий, тот же.
5. `CLAUDE.md`: в строке «Вид (T029, T032, T033 …)» перекрёстка добавить T037 и «серые шевроны входа остриём внутрь
   (`InputChevronColor`)»; в список задач — «T037 — серые шевроны входа у перекрёстка».

## Что не входит
- Шеврон выхода, пульс затора, частицы «тик-так», дырки, тело.
- Перспектива частиц под атомом (раздел спецификации «Перспектива») — отдельная задача.
- Самопроверку `--sim-selfcheck` не гонять: передачу не трогаем.

## Если серый пропадает на тёмном ореоле
Спецификация даёт запасной тон `#4d4268` (на ступень светлее). Поменять значение по умолчанию на него можно, только если при
ручной проверке шеврон входа не читается, — и написать об этом в отчёте (художник подтвердит).

## Критерии готовности
- Сборка `dotnet build Singulario.sln` без ошибок.
- Ручная проверка в игре: перекрёсток Ж/К/С/серый — на двух входах серые шевроны остриём к телу, на выходах — прежние шевроны
  тира остриём наружу; R четыре раза — все 4 ориентации, шевроны входа всегда на сторонах, противоположных выходам;
  пауза (пробел) — рисуются, не мигают; затор выхода — пульсирует только шеврон выхода; при отдалении шевроны входа
  исчезают вместе с шевронами выхода (`HoleHideZoom`).
- Отчёт: что сделано, что проверено, какой цвет по умолчанию оставлен.
