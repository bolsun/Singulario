# T013 — Главное меню, пауза, настройки, язык, автосохранение

Статус: выполнена (ветка `feature/main-menu`, влита в `experimental`).

Ветка: `feature/main-menu` от `experimental` (`git checkout -b feature/main-menu experimental`).
После отчёта — влить в `experimental` (CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: T008 (режимы), T009 (новая игра), T012 (подсказка управления), `SaveLoadPanel.cs`, HUD.

## 1. Главное меню
- При запуске — меню поверх поля (поле на фоне можно не показывать или затемнить).
- Кнопки:
  - **Продолжить** — если есть сохранённая игра (автосохранение, см. п. 4), загружает её;
  - **Новая игра** — если игры нет, одна эта кнопка вместо «Продолжить»; если игра есть — обе,
    «Новая игра» спрашивает подтверждение («текущая игра будет потеряна»);
  - **Язык** — переключатель Русский / English;
  - **Полный экран** — галочка;
  - **Громкость звука**, **Громкость музыки** — ползунки-заглушки (значение сохраняется,
    звука пока нет);
  - **Выйти из игры** — с диалогом подтверждения.
- Под кнопками — подсказка управления (та же, что в T012: WASD — камера, G — сетка; можно
  добавить остальные клавиши, которые уже есть: R, Q, M и т. д.).

## 2. Пауза
- Esc во время игры — открыть меню и поставить симуляцию на паузу; «Продолжить» или Esc —
  закрыть меню и снять паузу (если игра стояла на паузе до меню — не снимать).
- В меню паузы вместо «Новая игра / Продолжить» — «Продолжить» (закрыть меню), «Новая игра»
  (с подтверждением), остальное то же.

## 3. Язык
- Все строки интерфейса (меню, HUD, подсказки, задания ЧД, названия рецептов, кнопки панели) —
  через механизм перевода Godot (`Tr(...)`, таблица CSV или PO в `res://Data/Localization/`).
- Два языка: русский (по умолчанию) и английский. Переключение — сразу, без перезапуска.
- Тексты в логе (`GD.Print`) не переводить.

## 4. Автосохранение и настройки
- Игра автосохраняется в `user://` при выходе в меню, при выходе из игры и раз в N минут
  (настройка). Формат — тот же, что у экспорта.
- Настройки (язык, полный экран, громкости) — отдельный файл в `user://`, грузятся при запуске.
- Ручные Экспорт/Импорт остаются (для отладки и шаблонов).

## Не входит
Реальный звук, дизайн меню (достаточно аккуратного стандартного вида), несколько слотов
сохранения. Тесты производительности и долгие прогоны не делать (прототип: сборка + короткая
ручная проверка).

## Критерии готовности
- [x] Сборка без ошибок и новых предупреждений.
- [x] Первый запуск: только «Новая игра»; после игры и перезапуска — «Продолжить» загружает её.
- [x] Esc ставит паузу и открывает меню, повторный Esc возвращает в игру.
- [x] Переключение языка меняет все строки интерфейса сразу; выбор сохраняется.
- [x] Полный экран и громкости сохраняются между запусками.
- [x] «Выйти из игры» и «Новая игра» при существующей игре спрашивают подтверждение.
- [x] Ветка влита в `experimental`.

## Итог реализации
- `Settings.cs` — настройки в `user://settings.cfg` (язык, полный экран, громкости-заглушки,
  интервал автосохранения 1/2/5/10 мин, по умолчанию 5); `Main` грузит и применяет при запуске.
- `GameMenu.cs` — главное меню и меню паузы (создаётся `Main`, `CanvasLayer` 100,
  `ProcessMode.Always`). Пауза меню — `GetTree().Paused`, не связана с паузой по пробелу.
- Автосохранение — `user://autosave.json` (JSON экспорта, запись через временный файл): после
  «Новой игры», при открытии меню по Esc, при «Выйти» и закрытии окна, по таймеру. Пишется только
  после «Новой игры» / «Продолжить» / импорта в этом запуске.
- Кнопка «Новая игра» убрана с панели Экспорт/Импорт (решение пользователя).
- Перевод — `Data/Localization/en.po` (ключ — русская строка), `locale/fallback = "ru"`.
- Проверено: сборка; сценарий в Godot без окна (новая игра → автосохранение → Esc/Esc → смена
  языка в HUD → «Продолжить» при перезапуске). Внешний вид меню в окне — ручная проверка.
