# T020c — Круглое свечение обратно, смешение тиров вместо резкой границы

Статус: выполнена в `experimental`.

Маленькая доработка — прямо в `experimental` (CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: T020, T020b (`Scripts/GlowLayer.cs`, `Resources/Shaders/glow_spot.gdshader`, `apply_glow` в
`Resources/Shaders/nebula_background.gdshader`).

## Проблема
T020b (свечение в границах клеток, скруглённые квадраты) выглядит плохо — «плитки» под каждым объектом;
пользователь: раньше было лучше. Исходная проблема T020 была одна: где перекрываются ореолы двух тиров,
финальный проход берёт преобладающий тир, и цвет переключается скачком по прямой.

## Что сделать
1. **Откатить T020b** (`7708ff7`): круглые мягкие пятна `(1 − r²)²`, как было, радиусы — настройки
   (`AtomRadiusCells` 0,7, `StarRadiusCells` **2,5**, `BlackHoleRadiusCells` 3). Силы — текущие
   (атом 0,3, серый 0,18, звезда 0,45 / забита 0,35 / простой 0,2, ЧД 0,2).
2. **Смешение тиров** в `apply_glow` вместо «преобладающий тир»:
   - доли тиров `w_k = g_k / Σg` (R/G/B/A);
   - **дизеринг:** тир пикселя выбирается порогом Байера (со смещённой фазой, как у смены рампы
     ЧД/Сингулярность) по накопленным долям — пиксели тиров перемешаны пропорционально силе;
   - **мягкий свет:** цвет = взвешенная сумма цветов тиров по долям (тон — по общей яркости, как сейчас);
   - серое участвует так же (у него только тон 0).
   Где один тир — вид как в T020.
3. Сингулярность — без изменений.

## Не входит
Общее зарево, свет звёзд на туманность. Без замеров.
