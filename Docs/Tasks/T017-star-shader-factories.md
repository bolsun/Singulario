# T017 — Звезда-сборщик на шейдере: спокойные «станки»

Статус: поставлена.

Ветка: `feature/star-shader` от `experimental` (`git checkout -b feature/star-shader experimental`).
После отчёта — влить в `experimental` (CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: `Scripts/StarLayer.cs` (отрисовка звёзд, один MultiMesh, состояния), `Scripts/StarSet.cs`
(`Producing`, `Elapsed`, `Output`), `NucleusLayer.StarDuration`, `StarOutputCapacity`.
Эталон вида — https://claude.ai/artifact/FqKvF2pK3UhxWzjB4wgGT1 (блок «По правилам Singulario», «Состояния»).
Арт-библия (черновик): https://claude.ai/code/artifact/532b583b-5898-425e-ba25-6d8f6dfbba89 — «Плотность пикселя»,
«Движение и фабрика». Исходные шейдеры — `Resources/Shaders/ThirdParty/PixelPlanets/` (MIT, читать `README.md`).

## Цель
Заменить растянутый спрайт звезды (`star_gray_96px`, 96 → 288 px) шейдером: чёткая звезда на любом зуме и
любого размера (впереди гиганты 6×6 и больше). Звезда в фабрике — станок: вид спокойный, одинаковый для
тира, синхронный; движение сообщает состояние и не спорит с потоком частиц.

## Что сделать

### 1. Шейдер звезды
- На основе `star_body_calm.gdshader` (тело) и `star_blobs.gdshader` (корона); производный код — в
  `Resources/Shaders/ThirdParty/PixelPlanets/` рядом с `LICENSE` (или новый файл с шапкой «производная от …,
  MIT»). Вспышки (`StarFlares`) не переносить.
- Параметры вида по умолчанию (утверждены): `cells_a = 4`, `cells_b = 8`, `limb = 0.6`, `limb_start = 0.5`,
  сид 753 для всех тиров (настройка — сид на тир), дизеринг тела включён.
- Цвета — рампы тиров Singulario 32: тело — тона 4 → 1 рампы (светлый → тёмный), корона — тон 1.
  Источник рамп — таблицы `Resources/palettes/singulario32/palette_{yellow,red,blue}.png` (5 px: обводка + тона
  1–4) или те же цвета в коде — на выбор в плане. Белого на поверхности нет.
- Пиксельная сетка: 1 пиксель мира; при отдалении (зум < 1) — не мельче 1 пикселя экрана (без ряби).

### 2. Отрисовка
- Все звёзды — один MultiMesh (как сейчас); тир, состояние, прогресс — данные инстанса. Узлов на звезду нет.
- Размер тела и короны — настройки (тело около 2,2 клетки в диаметре, корона выходит за 3×3 — подобрать на глаз
  по эталону). Отладочная настройка `DebugVisualScale` (только вид, не занимаемые клетки) — посмотреть гиганта 6×6.
- **Время анимации — от тика симуляции**, не от кадра: фаза = (глобальный тик mod `LoopTicks`) / `LoopTicks`,
  `LoopTicks` кратен 256 (по умолчанию 512 ≈ 8,5 с при 60 тиках/с). Все звёзды тира синхронны; на паузе
  (пробел) анимация стоит. Смещение ячеек в шейдере за цикл — целое, цикл бесшовный.

### 3. Состояния (движение = состояние)
| Состояние | Условие (сейчас в коде) | Вид |
|---|---|---|
| Работает | `Producing && Elapsed < StarDuration` | поверхность дрейфует; мягкий пульс — **в палитре** (например, корона дышит размером или на ступень ярче), не умножением яркости |
| Простаивает | `!Producing` | поверхность замерла (одна фаза для всех), тона на ступень темнее, корона погашена |
| Выход забит | `Producing && Elapsed >= StarDuration` | поверхность замерла, тона обычные; красная дуга `#d23a4a` (как сейчас, но цвет из палитры); если забит дольше одного цикла рецепта — шеврон стороны выхода мягко пульсирует (`#ff6e5e` ↔ `#8c1c3a`) без наведения |
- Дуга прогресса рецепта остаётся; цвет — из палитры (тон 3 тира вместо белого).
- Задержку «дольше одного цикла» считать в `StarLayer` (это вид, не закон симуляции).
- Нынешнее свечение `ProducingGlow`/`ProducingPulse` (умножение яркости, цвета вне палитры) для новой звезды не
  использовать.

### 4. Дальний зум
- Ниже `StarLodZoom` (настройка, подобрать) — диск тона 3 тира с тоном 1 по краю, без анимации поверхности и короны.
  Звёзды видны поверх туманностей T015 и фона T016, как сейчас.

### 5. Сравнение
- **F6** — переключение «спрайт (как было) / шейдер» для всех звёзд, короткая надпись; строки — ключами в
  `Data/Localization/en.po`. Стартовый режим — шейдер. Выбор не сохраняется.

### 6. Всё остальное без изменений
Превью установки, значок рецепта и буфер при наведении, эффект поглощения, выдача, звезда-предмет в инвентаре.

## Не входит
Вспышка на событие (готовый атом), свет звезды на туманность, гиганты как механика, планеты, ЧД на шейдере,
тир З. Производительность — устройством кода (один MultiMesh, без узлов на звезду, LOD на отдалении), без замеров.
