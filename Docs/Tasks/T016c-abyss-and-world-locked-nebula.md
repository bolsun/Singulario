# T016c — Фон «Бездна» по умолчанию, туманность привязана к миру, F5 — мягкий свет

Статус: выполнена в `experimental`.

Маленькая задача — прямо в `experimental` (CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: T016, T016b (`Scripts/NebulaBackground.cs`, `Resources/Shaders/nebula_background.gdshader`).
Арт-библия (черновик): https://claude.ai/code/artifact/532b583b-5898-425e-ba25-6d8f6dfbba89, «Фон и туманность».

## Решения пользователя
1. **«Бездна»** (проверено в игре): пустота — самый тёмный цвет палитры, туманность на ступень темнее.
2. **Параллакс выглядит плохо**: объекты игрока кажутся плоскими. Причина (художник): параллакс
   применяется только к панорамированию (`bg = cam_pos·parallax + (p − screen/2)/zoom`), а при зуме фон
   масштабируется как поле — противоречивые сигналы глубины; к тому же свет ЧД стоит на мире, а текстура
   под ним уезжает («туманность проплывает сквозь прожектор»). Решение: туманность — часть того же
   пространства, привязана к миру.

## Что сделать
1. Новые умолчания `NebulaBackground`:
   | Настройка | Было | Стало |
   |---|---|---|
   | `Color0` | `#120e1d` | `#0a0812` |
   | `Color1` | `#1b1629` | `#120e1d` |
   | `Color2` | `#272038` | `#1b1629` |
   | `Color3` | `#372d4d` | `#272038` |
   | `BlackPoint` | 0.1 | 0.12 |
   | `Parallax` | 0.4 | 1.0 (фон движется ровно с полем) |
2. `default_clear_color` в `project.godot` — `#0a0812`.
3. Проверить, что при `Parallax = 1` узор дизеринга привязан к миру: при панорамировании едет вместе с полем,
   туманность под светом ЧД не смещается.
4. Закрытая территория теперь может оказаться не темнее открытого космоса — только сообщить в отчёте, как
   она выглядит (скриншот или описание). Не исправлять: вид закрытой территории решает художник отдельно.
5. **F5 — режим света: «Дизеринг» ↔ «Мягкий свет»** (эксперимент, пользователь хочет сравнить в игре):
   - «Дизеринг» — как сейчас: уровень → 4 ступени `Color0..3` → Байер.
   - «Мягкий свет» — тот же уровень (после света, `Gain` и `BlackPoint`) без ступеней и узора: плавная
     интерполяция по тем же четырём цветам (`Color0` при 0 … `Color3` при 1). Цвета вне палитры здесь
     допустимы — это осознанное исключение только для фона.
   - Если в тёмных тонах видны полосы — едва заметный шум по пикселям экрана (настройка силы, по умолчанию
     маленькая или 0 — на выбор в плане).
   - Переключение F5 независимо от F4 (текстура); короткая надпись с названием режима, как у F4; строки —
     ключами в `Data/Localization/en.po`. Выбор не сохраняется, стартовый режим — «Дизеринг».
   - Режим — один параметр шейдера; отдельного прохода не нужно.

## Не входит
Свет звёзд, ореолы, смена текстур, вид закрытой территории. Без замеров.

## Критерии готовности
- [x] Сборка без ошибок и новых предупреждений.
- [ ] Пустота почти чёрная (`#0a0812`), туманность — призрачная, у ЧД.
- [ ] Туманность и свет не смещаются относительно поля при панорамировании и зуме.
- [ ] F5 переключает «Дизеринг» / «Мягкий свет», название видно на экране; F4 работает в обоих режимах.
