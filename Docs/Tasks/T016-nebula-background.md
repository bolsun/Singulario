Контекст: арт-направление — концепты https://claude.ai/artifact/GMuWaY315saDJVjWmGnNxs (вариант A

## Цель
Попробовать в игре фон-туманность и выбрать вариант текстуры. Это прототип вида, не финальная
графика: пользователь посмотрит варианты по F4 и решит, куда идти дальше.

Лор: вселенная схлопнулась — звёзд на фоне нет. Туманность — остатки материи; она видна только в
свете Сингулярности (ЧД), к краям растворяется в темноте. Фон не должен забирать внимание у
объектов: только самые тёмные тона, без движения.

## Что сделать

### 1. Слой фона
- Новый узел `NebulaBackground` в своём файле, создаётся из кода (как `TerritoryLayer`/`GameMenu`),
  рисуется позади всего поля (сетка, атомы, месторождения, ЧД, звёзды — поверх).
- Бесконечный фон: один полноэкранный проход с шейдером; мировые координаты — из камеры (позиция,
  зум). Без огромных квадов и без узлов на чанк.
- Симуляцию не трогает. В `NucleusLayer` логику не дописывать — только чтение позиций и размеров ЧД
  (`NucleusLayer.BlackHoles`).

### 2. Шейдер
- **Плотность** — серая бесшовная текстура 512×512 (яркость = плотность), repeat, линейная
  фильтрация. Координата выборки = мировая × параллакс / `TexelWorldSize`.
  - `TexelWorldSize` — мировых единиц на тексель; стартово так, чтобы тайл был порядка 4–6 чанков.
  - `Parallax` — доля движения фона от движения поля (например 0.4).
- **Свет ЧД**: для каждой ЧД (не больше `MaxLights`, например 8 ближайших к центру экрана)
  `L = 1 / (1 + (d / R)²)`, `d` — мировое расстояние от центра ЧД (без параллакса, свет стоит на ЧД),
  `R` = `LightRadius` (в чанках). Сумма, ограничить 1. Уровень `v = плотность × L × Gain`, ограничить 1.
- **Цвет** — ступени палитры Singulario 32: `#1b1629` (пусто) → `#272038` → `#372d4d` → `#4d4268`.
  Между ступенями — стабилизированный дизеринг Байера 4×4:
  - клетка узора — `DitherPixel` пикселей экрана (стартово 3), одинакова при любом зуме — без муара;
  - сетка клеток привязана к фону: при панорамировании без зума узор едет вместе с фоном (смещение
    сетки = экранная позиция точки отсчёта фона по модулю клетки);
  - плотность и свет берутся в центре клетки — вся клетка одного цвета;
  - уровень ступени = `floor(v · 3 + b)`, `b = (Bayer + 0.5) / 16`, ступень не больше 3.
- Фон `#1b1629` закрывает экран целиком. `default_clear_color` в `project.godot` — оставить или
  поставить тот же цвет (на выбор, коротко в плане).
- **Дальний зум**: ниже `FadeZoom` (настройка, ширина перехода — тоже) туманность плавно гаснет к
  ровному `#1b1629`, чтобы мелкий повтор текстуры не рябил. Туманности чанков из T015 (если уже
  влиты) рисуются поверх фона и не должны с ним конфликтовать.

### 3. F4 — переключение вариантов
- Циклически: Облака → Дымка → Мрамор → Пыль → Выкл → Облака… Стартовый — Облака.
  | Вариант | Файл |
  |---|---|
  | Облака | `nebula_clouds_512.png` |
  | Дымка | `nebula_filaments_512.png` |
  | Мрамор | `nebula_flow_512.png` |
  | Пыль | `nebula_dust_512.png` |
  | Выкл | фон как до задачи |
- При переключении — короткая надпись с названием варианта (1–2 с). Новые строки — сразу ключи в
  `Data/Localization/en.po` (CLAUDE.md, T013).
- Выбор не сохраняется — это отладочный переключатель. F3 занята HUD производительности.

### 4. Настройки
`TexelWorldSize`, `Parallax`, `LightRadius`, `Gain`, `DitherPixel`, `FadeZoom` (+ ширина перехода),
`MaxLights`, цвета ступеней — `[Export]` на узле (или в одном месте), чтобы пользователь подбирал сам.

## Не входит
Ореолы под атомами, свет звёзд игрока, окраска туманности в тон ЧД/звёзд, отсутствие туманности в
закрытой территории, второй слой текстуры против заметного повтора, прогиб сетки, подключение палитр
тиров `Resources/palettes/singulario32/palette_*.png`. Производительность — устройством кода (один
полноэкранный проход), без замеров и долгих прогонов.

## Заметки и риски
- Текстуры добавлены без `.import` — Godot импортирует их при открытии редактора. Если это мешает
  (сборка/запуск без редактора), грузить через `Image.LoadFromFile` + `ImageTexture` — на выбор в плане.
- Пиксельные атомы при нецелом масштабе слегка «дышат» — к этой задаче не относится.
