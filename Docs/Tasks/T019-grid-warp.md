После отчёта — влить в `experimental` (CLAUDE.md, «Процесс»). В `main` не пушить.
Контекст: `Scripts/GridDraw.cs` (сетка G: линии клеток/чанков, пороги зума, цвета — настройки),

Эталон вида — `Docs/Tasks/T019-grid-warp-reference.png`, **средняя панель** (сила 1/4 клетки).
Арт-библия (черновик): https://claude.ai/code/artifact/532b583b-5898-425e-ba25-6d8f6dfbba89 — «Фон и туманность», сетка.

## Цель
Сетка пространства «проваливается» под массивными объектами (ЧД, звёзды), как ткань. Сетка нужна для точной
расстановки, поэтому прогиб **только в клетках самого объекта**: линии соседних клеток остаются прямыми.
Решения пользователя: прогиб начинается в границах объекта, граничные линии объекта тоже гнутся, сила 1/4 клетки,
выключается по Shift+G (F7 занята редактором Godot — «Пауза проекта»).

## Что сделать

### 1. Отрисовка сетки
- Прогиб на CPU-линиях неудобен — рекомендуется рисовать сетку полноэкранным шейдером (как `NebulaBackground`):
  линия толщиной 1 px экрана на любом зуме (через производные координат), координаты мира — от камеры.
  Другой способ — на выбор в плане, если он даёт тот же вид.
- При выключенном прогибе вид **точно как сейчас**: цвета `LineColor`/`ChunkLineColor`, пороги `CellGridHideZoom`/
  `GridHideZoom`, границы чанков в режиме клеток, режим чанков на отдалении, переключение G, порядок слоёв
  (над фоном, под атомами).

### 2. Прогиб
- Для каждого объекта: след — квадрат его клеток (ЧД — `Size`×`Size`, звезда — 3×3), центр `c` — центр следа,
  полусторона `h` = N·клетка/2. Линии **втягиваются к центру**: координата, по которой ищется линия,
  `q = p + dir·s`, `dir = normalize(p − c)`.
- Величина (как в эталоне):
  - `s = Strength · клетка · g · fall · near`;
  - `g = 1 − 0.45·min(u, 1)`, `u` — чебышёвское расстояние до центра / `h` (в центре 1, на границе следа 0,55);
  - `fall` = 1 внутри следа и плавно спадает до 0 **за полклетки снаружи** — по скруглённому квадрату, чтобы у
    углов зоны не было изломов линий;
  - `near = min(1, |p − c| / (0.35·h))` — у самого центра прогиб гаснет.
- Граница следа тоже прогибается; следующая линия соседей (1 клетка снаружи) — прямая.
- `Strength` по умолчанию **0,25** (доля клетки) — отдельные настройки для ЧД и звезды (обе 0,25); у будущих
  гигантов формула масштабируется по размеру следа сама.
- Объектов в шейдер — не больше `MaxWarpObjects` (например, 16 ближайших к центру экрана); вне экрана не учитывать.
- Прогиб — только вид; симуляция, установка и выделение клеток по-прежнему по прямой сетке.

### 3. Shift+G
- **Shift+G** — прогиб вкл/выкл, короткая надпись (как у F4/F5); строки — ключами в `Data/Localization/en.po`.
  F7/F8 не использовать: в редакторе Godot это «Пауза» и «Остановить проект» (T020 уже перенесла свечение с F8 на L).
  Обычная G (без Shift) по-прежнему включает сетку — в `GridDraw` проверять, что Shift не нажат.
- Выбор сохраняется в `Settings` (`user://settings.cfg`), по умолчанию — вкл.

## Не входит
Растяжение сетки при выбросе (GDD), закручивание туманности у ЧД, прогиб на карте слоя 3, звёзды-предметы.
Производительность — устройством кода (один полноэкранный проход, ограниченный список объектов), без замеров.
