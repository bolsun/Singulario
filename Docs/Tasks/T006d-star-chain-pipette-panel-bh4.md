## 1. Передача звезда → звезда
Сейчас не работает: звезда кладёт готовый атом грузом на клетку выхода, а соседняя звезда
принимает только атомы, довезённые вращателем или бросателем.
Надо (атом должен быть нужен рецепту принимающей звезды и в её буфере должно быть место):
- **Выход смотрит прямо в другую звезду** (клетка выхода — клетка другой звезды): готовый
  атом передаётся в неё напрямую, минуя груз. Если не нужен или нет места — звезда ждёт,
  как при занятом выходе.
- **Груз на клетке выхода стоит рядом с другой звездой**: атом, выложенный звездой, считается
  доставленным — соседняя звезда забирает его, как атом, довезённый вращателем.
- Анимация поглощения из T006c — и для этой передачи.

## 2. Пипетка Q для звёзд (и ЧД)
- Q над звездой выбирает инструмент звезды её тира (★Ж/★К/★С).
- Q над ЧД выбирает инструмент ЧД.
- Q на пустой клетке снимает инструмент, Q над атомом — как сейчас (T006b).

## 3. Порядок кнопок на панели
- Кнопки звёзд — перед кнопкой ЧД, чтобы группа звёзд не разрывалась на две строки.

## 4. ЧД 4×4
- Размер новой ЧД по умолчанию — 4×4 клетки (`BlackHoleLayer.BlackHoleSize = 4`).
  Размер уже хранится у каждой ЧД: ЧД из старых сохранений остаются своего размера.
- Горизонт и захват работают для любого размера (проверить на 4×4: 16 клеток горизонта).
